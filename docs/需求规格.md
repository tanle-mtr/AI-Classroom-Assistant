# AI 课堂助手 — 需求规格书（最终确认版）

> 确认日期：2026-09-24 · 与用户逐条确认后定稿

## 1. 总体形态

Windows 桌面助手，**托盘常驻、开机静默自启**。按课程感知课堂 → 下课自动产出 md 文档 → 分类导出 → 网页挂载 + 内网穿透远程访问。多语言实现：Python（核心逻辑）、C#（托盘/自启/关机钩子）、Vue（网页控制台）、PowerShell（开机/关机脚本）。

## 2. 模型

- 软件启动时自动执行 `ollama list` 拉取已安装模型，**界面让用户选择主力模型**（不写死）
- 自动探测硬件（CPU/GPU/内存），给出模型规格建议
- **c：Modelfile 打包专属模型**（内置技能+提示词 → 定制模型）
- **b：教科书本地知识库 RAG**（查阅教科书）

## 3. ClassIsland 对接

- 优先查 ClassIsland GitHub 仓库有无暴露本地端口/API，**有则用，没有退回配置文件监听**（读取当前课程状态）

## 4. 感知（共享模式，不独占）

- 麦克风走 WASAPI 共享模式采集；摄像头走系统共享通道，不设独占；检测到其他程序独占时等待/重试。**其他进程可同时使用麦克风/摄像头**
- 上课期间：麦克风（ASR 转写课程内容）+ 摄像头（教室状态/识别学生/识别老师）+ 屏幕（实时分析，不保存原始屏幕录像）
- **拖堂判定**：以 ClassIsland 下课事件为起点 → 屏幕仍活跃（PPT 翻页/电脑操作）+ 摄像头看到绝大多数学生未离开座位 → 判拖堂。麦克风不参与拖堂判定（只用于课程转写与分贝监控）

## 5. 下课自动产出（md 格式）

| 课型 | 产出 |
|---|---|
| 新授课 | 老师课堂总结 + 学生总结（重难点）+ 导学案 + 思维导图 |
| 评讲作业/试卷课（评奖题目） | 老师课堂总结 + 学生总结 + 导学案（**不出思维导图**） |
| 考试/自习课 | 只有老师总结：每分钟分贝折线图 + 平均分贝等 |

- 老师总结要素：课堂质量评价、哪个部分可细讲、哪个可讲短、防拖堂建议
- 思维导图：Markdown 内嵌 Markmap；优先查软件自带 skill 库有无现成 skill，无则用 Markmap 方案

## 6. 监控模式

- **默认开启**：开机自动开始录制，关机自动导出整理
- 录制内容：**摄像头画面 + 录音**，按课程切片
- **保留 14 天**自动清理监控录像；md 文档类产物永久保留
- 屏幕只做实时分析，不存档

## 7. 座位表

- 上传图片初始化（OCR 识别名字/座位）
- 上课时摄像头**自动录入学生人脸建档**（首次建档方案）
- 自动检测座位变化并**更新座位表**（可导出）

## 8. 教科书

- 首次打开：询问年级 → 自动定位地区 → 匹配教材版本（人教版/粤教版等）→ 显示教材清单确认
- 获取：优先官方公开免费渠道（如国家中小学智慧教育平台）；无免费版提示用户导入 PDF；**不做盗版绕行**
- 电子书转文本 → 本地知识库 RAG（向量检索）

## 9. 内置 skills（md 格式技能库）

- **纯文本 AI 识图**：调用 Ollama 本地视觉模型（qwen2.5-vl/llava 等）做 OCR/图像描述，结果转为文本喂给纯文本模型
- **md 编写 skill 机制**：SKILL.md 风格技能包，模型按技能文件执行任务
- 实用 skill：课堂总结、导学案、思维导图、分贝统计、座位表维护、教科书问答等

## 10. 导出与网络

- 导出文件夹按 **日期/课程/类型** 分类命名
- 导出目录用 **OpenList** 挂载（网页浏览/下载）
- **Cloudflare Tunnel（cloudflared）内网穿透**：软件自动下载安装 → 引导登录授权 → 自动建隧道开机自启；tunnel token 由用户从 Cloudflare 面板粘贴进软件，以 `--token` 方式运行；暴露 OpenList + 课件上传端口；访问者凭**访问链接/令牌**访问
- **自动查询公网 IP**（可选），配域名 DDNS 可选
- **课件上传**：老师远程网页上传，按**科目自动分类建文件夹**（没有的科目自动创建），无访问口令
- **cf 隧道代理**：软件内置隧道代理配置，可把本机任意端口/局域网服务（OpenList、WebUI、代理端口等）经 Cloudflare Tunnel 代理出去，访问者凭令牌经隧道访问
- **UI 效果图**：桌面托盘主界面、网页控制台、课堂总结/监控视图（视觉稿见 docs/ui-design.md）

## 11. 隐私与合规

- 所有敏感数据仅本机处理；默认不存人脸、不上传原始音视频（用户明确要求录制的监控录像除外，仅本机保存）
- 校园部署需告知班级

## 12. 遗留/开放项

- 无（Cloudflare Tunnel 方案已定，不依赖 VPS）
